# Curriculum rewrite rules

- Every task uses four primary sections in Azerbaijani and English: purpose, prerequisites, step-by-step instructions, and deliverables.
- Task 1 of every independent project starts with a new student-owned repository built from scratch.
- A later task reuses a repository only when it explicitly continues a previous artifact; otherwise it starts a new repository.
- Preserve track-specific safety guidance, tests, acceptance criteria, and submission requirements.
- Avoid assuming students have paid tools, API access, Docker, or a hosted service; provide a safe local/mock alternative where feasible.
